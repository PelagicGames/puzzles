How to play

The rules of the road

Nine tiles, one board, one path. Here is everything you need to know in order to play, with some helpful examples.

1. The goal

The board is nine squares by nine, divided into nine three-by-three tiles. You are given nine three-by-three tiles. Drag every tile into a space so that the path squares join up into a single path that starts at one edge of the board, visits every path square, and finishes at another point on the edge.

  • Tiles cannot be rotated or flipped, only moved.
  • Tiles cannot overlap, so each space holds exactly one tile.
  • Every tile is different and every tile holds at least one path square.
  • Each puzzle has exactly one solution.

2. Path squares

Each small square is either empty or holds a path element: a straight, a right-angled corner, or a crossroads. Paths only travel up, down, left and right, and never split or stop part-way across the board.

3. The tiles

Tiles cannot be turned or flipped: each one is placed exactly as printed. Some puzzles start with fixed tiles already on the board: these are printed in the same colour as the board and cannot be moved. Moveable tiles are slightly lighter.

4. Joining tiles

Where a path reaches the side of a tile, the neighbouring tile must continue it. Paths may only sit next to each other when they are directly joined: no two path squares may touch side by side without connecting.

5. Crossroads

At a crossroads the path always goes straight on, never turning. A crossroads is therefore travelled twice: once horizontally and once vertically. In these examples, the dots mark the two ends of the path.

6. Two ends, one path

The finished path touches the edge of the board exactly twice: once where it starts and once where it ends. Every other path square must lie on the route between them, so there can be no separate loops or stray path squares.

7. Clues

To make sure there is only one answer, a puzzle may fix some tiles in place, mark one or both ends of the path with a dot beside the board, or both. A marked end must be used.

8. Checking your answer

Once every tile is on the board, a pen traces the path from one end. If the arrangement is right, the pen runs all the way to the other end and the puzzle is stamped solved. If not, the pen stops where the route goes wrong and red marks show the problems: a cross at a broken join, a zig-zag where paths are adjacent without connecting, red path squares that were never visited, and a ring around an end that was missed.
