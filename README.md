This is a generic repository for puzzle game prototypes.

- **Light Discs** is a colour-and-shape filter puzzle.
- **Mapominoes** is a local multiplayer country-chain memory game with
  fuzzy country lookup, challenge and automatic checking modes, adaptive
  first-round route validation, scores, and an end-of-round world map.
- **Crosspath** is a newspaper-style tile puzzle: drag nine 3x3 path
  squares into a 9x9 board to make one route from edge to edge, going
  straight over every crossroads.
- **Word Quiz** is a word game: read a dictionary definition with the
  answer blanked out and spell it from wooden letter tiles, then challenge
  friends or ask them for help with a direct link.

Progress is saved in local browser storage. If the browser blocks local
storage use, the games still play but solves are remembered only for the
current session.
